1. The protocol

    • browser looks up address of server
      associated with website opens TCP
      connection to port 80 (default web port for HTTP traffic)
    • browser sends
      GET /18_http.html HTTP/1.1
      HOST: eloequent.net
      User-Agent: your browser name
    • information sent by client is request
    • first word is method of the request GET (GET, DELETE, PUT)
    • resource path
    • HTTP/1.1 = version of HTTP protocol
    • HTTP version 2 = loads faster
    • status code with 2 = request succeded
    • HTTP Status code (ex 404, 5)
    • headers
    • client server are free to decide
      which headers to include (ex Content-Type)
    • GET and DELETE dont send along any data
      PUT and POST request do

    • FileReader also fires an error event

          function readFileText(file) {
  return new Promise((resolve, reject) => {
    let reader = new FileReader();
    reader.addEventListener(
      "load", () => resolve(reader.result));
    reader.addEventListener(
      "error", () => reject(reader.error));
    reader.readAsText(file);
  });
}
