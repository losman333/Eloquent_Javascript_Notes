1. The protocol

    • browser looks up address of server
      associated with website opens TCP
      connection to port 80 (default web port for HTTP traffic)
    • browser sends
      GET /18_http.html HTTP/1.1
      HOST: eloequent.net
      User-Agent: your browser name
    • information sent by client is request
    • first word is method of the request GET (GET, DELETE, PUT)
    • resource path
    • HTTP/1.1 = version of HTTP protocol
    • HTTP version 2 = loads faster
    • status code with 2 = request succeded
    • HTTP Status code (ex 404, 5)
    • headers
    • client server are free to decide
      which headers to include (ex Content-Type)
    • GET and DELETE dont send along any data
      PUT and POST request do

  2. Browser and http

    • browser will make request
      when url is entered
    • html can include forms
    • submit button = content packed into
      an HTTP request and browser navigates
      to the result of that request
    • GET used for request without side
      effects but ask for information
    • POST for request that change something

  3. fetch

    • fetch = returns pomise that
      resolves to a Response object
      holding information about servers response
      such as a statuts code and headers
    • fetch uses argument of URL that
      should be requested
      • first argument URL
        / replaces current path
    • text method
    • 405 = method not allowed
    • PUT or POST request include body option
