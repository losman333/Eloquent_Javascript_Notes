1. Modular Programs

    • Modules = piece of program that specifies which other pieces it relies on
      which functionality it provides for other
      modules to use (its interface)

  2. ES Modules
    • Scripts = bindings are defined in global scope
    • Modules = seperate scope support import and export keywords
    • export = can be put in front of a function, class
      or binding definition to indicate binding is part of modules
      interface

      export function dayName(number) {

    • import = makes bindings from another module available
      in current mode, identfied by quoted strings

      import {dayName} from "./dayname.js";


    • export default = before expression
      used for modules
      that only export single binding

    • import * asterik = imports all binding from module
      at the same time
      usefule when using a lot of different exports
