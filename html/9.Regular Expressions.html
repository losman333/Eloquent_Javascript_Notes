    20. summary

    1. expressions objects that represent patterns
      in strings
      use their own language to express these patterns

    2. has method test to test whether given string
      matches it

    3. has method exec = returns array containing
      all matched groups

    4. index property = indicates where match started

    5. i = makes match case insensitive

    6. g = makes expression global causes replace
      method to replace all instances instead of just first

    7. y = makes expression sticky

      8. will not search ahead and skip part of string when looking
      for match

    8. u = turns on unicode mode enables \p syntax
      fixes numbers of problems around handling
      characters that take up two code units
