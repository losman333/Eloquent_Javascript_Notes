1. Document Structure
    • document = nested set of of boxes
    • Document Object model or DOM = object that represents
      which boxes and text it contains
    • documentElement = global binding Document
      that gives acces to the objects
    • head and body = properties that point
      to html elments
  2. Trees

    • Node.TEXT_NODE = code 3 (Text)

    • leaves are text nodes, arrows indicate parent-child
      relationships between nodes

  4. Moving throught the tree
